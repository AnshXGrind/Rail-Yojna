# Constraint Model

## Constraint classes

### Safety
- minimum block duration
- minimum clearance
- required isolation/protection
- required personnel

### Operational
- train occupancy
- maintenance duration
- maintenance windows
- section/track compatibility

### Resource
- crew/resource availability
- machine availability
- material availability

### Data

Missing or unjoinable source information is a data gap.

## Status semantics

`PASS` · `CONFLICT` · `DATA_GAP` · `REVIEW`

A data gap is not equivalent to a pass.
