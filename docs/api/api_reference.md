# API Reference

FastAPI is the backend API surface.

## Local

`http://127.0.0.1:8000`

Interactive documentation: `/docs` and `/openapi.json`.

## API areas

- **Risk:** asset risk prediction and monitoring
- **Planning:** maintenance-plan summaries, tasks, and metrics
- **Blocks:** candidate generation and block assessment
- **Recommendations:** ranked decision-support recommendations
- **Decisions:** human approve / modify / reject actions
- **Reports:** maintenance/problem-report inputs
- **Audit:** decision and prediction traceability

A recommendation never implies operational authority.
